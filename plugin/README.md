# plugin

## Overview

Holds the Obsidian plugin that goes with the Vitrine theme. The folder name `vitrine` matches the plugin id, so the built folder can be copied straight into a vault's `.obsidian/plugins/`.

## Subdirectories & Boundaries

- vitrine: [`./vitrine/README.md`](./vitrine/README.md). The plugin package: manifest, esbuild build into `main.js`, and the TypeScript source for presets and settings, refraction on floating panels, the Windows window material and diagnostics.
